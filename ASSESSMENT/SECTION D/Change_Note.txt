Change Note & Bug Explanation:
1. Discount Calculation Scope: The AI's initial version incorrectly computed the 10% loyalty discount across the combined total including GST and delivery fees, violating the requirement to apply it strictly to the item subtotal. I corrected this logic to calculate the discount exclusively on the subtotal before adding taxes and flat delivery charges.
2. Unhandled Crash on Non-Numeric Inputs: The previous order count was read using an unvalidated int(input(...)), causing an unhandled ValueError and crashing the app when non-numeric text like "five" was entered. I wrapped the input inside a while True loop with a try-except block to guarantee safe, repeated re-prompting.
3. Iterative Input Validation: The AI's negative price check failed to re-prompt continuously until valid data was provided. I enclosed all numeric inputs (item count, individual item prices, and previous order count) within robust try-except loops to ensure non-negative, valid numbers before continuing execution.
